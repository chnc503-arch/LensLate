# LensLate

**Офлайн-переводчик текста на изображениях для Android.** Распознаёт русский, английский и японский, переводит на устройстве и накладывает перевод поверх оригинала — с сохранением положения, цвета, начертания и фона текста.

### Установка

1. Скачайте APK на телефон (или перекиньте файл с компьютера).
2. Откройте файл и разрешите установку из этого источника, если система попросит: **Настройки → Безопасность → Установка неизвестных приложений**.
3. Нажмите **Установить**. Если Play Protect предупредит о незнакомом приложении — это ожидаемо для debug-подписи; устанавливайте только сборки из этого репозитория.

При первом запуске может понадобиться интернет и Google Play services: ML Kit докачивает модели распознавания и перевода. После загрузки распознавание и перевод работают на устройстве офлайн. Русский OCR (Tesseract) встроен в APK и доступен сразу.

## Возможности

- **Три языка** — русский, английский, японский; движок и язык определяются автоматически.
- **Мультипроходный OCR** — несколько вариантов предобработки (контраст, бинаризация, апскейл, выравнивание наклона), оценка качества и слияние результатов.
- **Подавление фантомного текста** — структурный анализ штрихов и однотипных глифов отсекает «буквы» на логотипах, одежде, предметах и текстурах.
- **Интеллект документа** — классификация изображения (литературный текст, манга, технический/научный текст, документ); исторические фото и логотипы внутри документа защищены от перевода.
- **Наклонный текст** — автоматический deskew с проверкой нескольких гипотез и переносом координат в исходное изображение.
- **Сохранение стиля** — цвет (в том числе градиент вдоль строки), размер, жирность, наклон, межбуквенные интервалы и восстановление фона под переводом.
- **Чистое наложение** — маска стирания подстраивается под ширину края глифов, а едва различимый текст стирается вместе с текстурой, поэтому под переводом не остаётся исходных букв.
- **Низкая уверенность** — блоки, распознанные с уверенностью ниже 0.70, не заменяются переводом: оригинал остаётся как есть.
- **Полноэкранный просмотр** — исходное фото и результат можно приближать и рассматривать в деталях.
- **Лаборатория** — экспериментальные режимы OCR, метрики качества, превью вариантов предобработки и диагностика пайплайна.
- **Стресс-тест цвета** — прямо в приложении прогоняет градиент, замыленность, пересвет и низкий контраст и сравнивает способы подбора цвета наложения.

## Как это работает

```
Фото
 ├─ подготовка: ориентация, рабочий масштаб, контраст, deskew, варианты предобработки
 ├─ OCR: ML Kit (латиница/японский) + Tesseract (кириллица), несколько проходов
 ├─ отбор: оценка кандидатов, слияние регионов, фильтрация фантомов
 ├─ язык: определение по Unicode + ML Kit Language ID
 ├─ перевод: ML Kit Translate на устройстве
 ├─ стиль: цвет, размер, жирность, наклон, интервалы по каждому глифу
 └─ рендеринг: восстановление фона и наложение перевода поверх оригинала
```

## Сборка из исходников

Понадобятся **JDK 17** и **Android SDK Platform 35**.

```bash
cd LensLate

# юнит-тесты
./gradlew :app:testDebugUnitTest

# debug APK
./gradlew :app:assembleDebug
```

На Windows используйте `gradlew.bat`. Готовый файл появится в
`app/build/outputs/apk/debug/app-debug.apk`.

Если SDK не найден автоматически, укажите путь в `LensLate/local.properties`:

```properties
sdk.dir=C\:\\path\\to\\Android\\Sdk
```

Release-сборка (`:app:assembleRelease`) не подписана — для распространения настройте собственный keystore.

## Ограничения

- APK собран с debug-подписью и предназначен для ручной установки и тестирования.
- ML Kit требует наличия Google Play services; модели распознавания и перевода загружаются при первом использовании.
- В комплекте только русская модель Tesseract (`rus.traineddata`); остальные языки распознаются через ML Kit.
- Приложение не отправляет изображения на серверы: распознавание и перевод выполняются на устройстве.

## Тесты и проверка на ПК

122 модульных теста на JVM: геометрия и координаты, слияние регионов OCR, фильтрация артефактов, определение формул, стиль и градиенты, интеллект документа, терминологический словарь, профиль края глифов.

```bash
cd LensLate && ./gradlew :app:testDebugUnitTest
```

Отдельного desktop-приложения нет намеренно: распознавание (ML Kit, Tesseract), перевод и отрисовка (`Canvas`, `StaticLayout`) — Android-компоненты, и их копия на ПК неизбежно разошлась бы с телефонной версией. Вместо этого чистая логика цвета, градиентов и геометрии вынесена в обычный Kotlin и проверяется на JVM без телефона:

- `ComplexBackgroundLabTest` — синтетические страницы с текстурой, бликами и плавно меняющимся цветом текста; проверяет, что цвет каждого глифа восстанавливается по локальному фону, а градиент не схлопывается в один цвет;
- `StyleStressLabTest` — градиент на текстуре, замыленный кадр, пересвет и низкий контраст; на одних и тех же пикселях сравнивает общий фон страницы, локальный фон из скана и экспериментальный пиковый сэмплер и печатает ошибку каждого способа в процентах;
- `InkColorSamplerTest` — оценка локального фона и выбор пикселей ядра глифа;
- `tools/lab/generate_complex_pages.py` — детерминированные сложные страницы (постер с бликами и градиентом, документ с градиентным текстом, японская вывеска, замыленный кадр, пересвет, низкий контраст) для проверки на устройстве:

```bash
python tools/lab/generate_complex_pages.py
```

Готовые изображения лежат в `tools/lab/pages/`. Саму отрисовку и OCR всё равно проверяйте на телефоне: JVM-тесты не заменяют Android-рендерер.

Те же четыре стресс-кейса можно прогнать прямо в приложении: вкладка **«Тестовые функции» → «Качество наложения» → «Прогнать стресс-тест»**. Пиковый сэмплер пока живёт только в этой лаборатории и не влияет на обычное сканирование.
